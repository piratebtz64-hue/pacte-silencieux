# Contributing to Le Pacte silencieux

Thank you for your interest in contributing! Here's how you can help:

## 🚀 Getting Started

1. **Fork the repository** on GitHub
2. **Clone your fork** locally:
   ```bash
   git clone https://github.com/your-username/pacte-silencieux.git
   cd pacte-silencieux
   ```

3. **Create a new branch** for your feature:
   ```bash
   git checkout -b feature/your-feature-name
   ```

4. **Install dependencies**:
   ```bash
   npm install
   ```

5. **Set up environment variables**:
   ```bash
   cp .env.example .env.local
   # Edit .env.local with your Supabase credentials
   ```

6. **Run the development server**:
   ```bash
   npm run dev
   ```

## 📝 Making Changes

- Follow the existing code style (TypeScript, Tailwind CSS)
- Keep commits atomic and descriptive
- Test your changes locally before submitting a PR
- Update relevant documentation

## 🔍 Code Style

- Use **TypeScript** for type safety
- Format with Prettier (runs automatically on commit)
- Follow the existing component structure
- Add comments for complex logic

## 🧪 Testing

Before submitting a PR:
```bash
npm run lint        # Run linter
npm run build       # Build the app
npm run type-check  # Check TypeScript
```

## 📤 Submitting a Pull Request

1. Push to your fork:
   ```bash
   git push origin feature/your-feature-name
   ```

2. Open a **Pull Request** with:
   - Clear description of changes
   - Reference to related issues (if any)
   - Screenshots for UI changes

3. Wait for review and feedback

## 🐛 Reporting Issues

Found a bug? Please open an issue with:
- Clear description of the problem
- Steps to reproduce
- Expected vs actual behavior
- Screenshots (if applicable)

## 💡 Feature Requests

Have an idea? Open a discussion or issue with:
- Why this feature would be useful
- How it aligns with the project's philosophy
- Proposed implementation (if you have one)

## 📋 Code of Conduct

- Be respectful and constructive
- Focus on the code, not the person
- Help others learn and grow
- Maintain the silent, peaceful spirit of the project

## 🙏 Questions?

Feel free to open a discussion on GitHub or reach out to contact@pacte-silencieux.fr
